# Initial Project Setup

## Status

**Accepted (8 Aug 2026)**

## Context

Create a task planning system like Sunsama to help with my own planning processes.

Use modern and familiar languages and frameworks.

Focus on delivery speed over engineering perfection.

## Decision(s)

- Tech stack: Deno, TypeScript, Deno KV, Deno Deploy
- Start project setup from the [Deno template in my dotfiles repo](https://github.com/bcm-works/dotfiles/tree/main/dev/templates/deno-typescript)
- All code inside of `/src/`
- Shared high-level docs, designs and other artifacts in other top-level directories
- AI Code Gen configuration at the top level
- Docs in Markdown format that follow a logical structure, and link to each other when relevant

## Consequences

- Deno KV is not completely stable, so some tech debt will arise as that evolves over time
